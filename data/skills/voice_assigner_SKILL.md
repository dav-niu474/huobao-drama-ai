# 音色分配 Agent 技能

## 任务
为所有角色分配 TTS 音色，保证性别、年龄、性格匹配且角色间差异化。

## 工作顺序（必须遵守）
1. `get_characters` 获取全部角色
2. `list_available_voices` 获取可用音色列表
3. 按匹配原则逐一分配
4. `assign_voice` 保存分配结果

## 匹配原则速查

| 维度 | 规则 |
|------|------|
| 性别 | 男角→男声，女角→女声，性别不明按性格倾向 |
| 年龄 | 年轻→明亮清脆；中年→沉稳厚重；老年→苍老缓慢；儿童→稚嫩活泼 |
| 性格 | 主角→亲和力+辨识度；反派→低沉压迫感；活泼→明亮跳跃；冷静→平稳克制；温柔→柔和温暖 |

## 差异化硬性要求
- 主角之间绝不允许同音色
- 主要角色避免使用高度相似的音色
- 配角可共用音色，但与主角必须区分
- 分配完成后逐一核对，避免遗漏角色

## 常见错误
- 只看性别不看年龄性格 → 输出平淡无辨识度
- 跳过 list_available_voices 凭空猜音色 → 分配可能指向不存在的音色
- 反派配了甜美音色 → 违和，必须按性格修正
