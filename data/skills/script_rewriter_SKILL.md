# 剧本改写 Agent 技能

## 任务
将小说、故事原文改写为标准影视剧本格式，保留主线信息，补全画面化表达。

## 输出格式规范

### 场景标题行
```
场次N  内景/外景  地点  日/夜
```
示例：`场次1  内景  咖啡馆  日`

### 动作描述
- 现在时态、可视化语言，只写镜头能拍到的东西
- 不写心理活动原文，转化为表情/动作/特写

### 对白
```
角色名
（情绪提示）
对白内容
```
- 对白口语化、短句优先，单句不超过 20 字
- 括号注释只写情绪/动作提示，不写解释

## 短剧改编节奏
- 每 30-60 秒需要一个钩子（冲突/反转/悬念）
- 前 3 场必须建立主角处境与核心冲突
- 单场戏不超过 2 分钟，超长对话拆分插入动作
- 每集结尾留卡点

## 改写原则

| 原则 | 说明 |
|------|------|
| 忠实主线 | 保留关键情节、人物关系与因果链 |
| 可视化 | 内心独白转为动作、表情、闪回 |
| 精简 | 合并重复信息，删掉无效支线 |
| 台词升级 | 书面语转口语，符合角色身份 |

## 常见错误
- 大段旁白代替画面 → 必须转成动作与对白
- 场景标题缺失 → 每场必须有内/外景+地点+时间
- 角色名前后不一致 → 统一用一个主名，别名在首次出现时注明
