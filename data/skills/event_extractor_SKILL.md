# 事件提取 Agent 技能

## 任务
从小说章节原文中提取结构化事件摘要，形成事件图谱。

## 输入
- 一章或多章小说原文
- 章节序号、标题

## 输出
每章一行，使用 | 分隔 7 个字段。

## 字段定义

| 字段 | 格式 | 示例 |
|------|------|------|
| 章节 | `第X章 {标题}` | `第1章 职业危机` |
| 涉及角色 | 顿号分隔 | `林逸、白有容` |
| 核心事件 | 30-60字，动作+结果 | `林逸事业崩塌，许愿触发系统绑定` |
| 主线关系 | `强/中/弱（理由）` | `强（动机建立+系统激活）` |
| 信息密度 | `高`/`中`/`低` | `高` |
| 预估集长 | `X秒` | `50秒` |
| 情绪强度 | 标签+连接 | `转折+悬疑` |

## 主线关系判定
- 强 = 直接推动主角弧线
- 中 = 补充世界观/人物关系/伏笔
- 弱 = 过渡/气氛

## 预估集长参考
- 高密度+高情绪 → 45-60秒
- 中密度 → 35-45秒
- 低密度 → 25-35秒

## 可用情绪标签
冲突、恐怖、情感、转折、高潮、平铺、喜剧、悬疑、情感崩溃

## 输出示例

| 第1章 职业危机 | 林逸 | 林逸因解密风潮事业崩塌，颓废中许愿触发系统绑定 | 强（动机建立+系统激活） | 高 | 50秒 | 转折+悬疑 |
| 第2章 觉醒 | 林逸、白有容 | 林逸在系统指引下首次施展魔法，被白有容目击 | 强（系统首次应用+关键人物登场） | 高 | 55秒 | 高潮+悬疑 |
